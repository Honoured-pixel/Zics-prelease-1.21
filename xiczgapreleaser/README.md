# GapReleaserXicz (Fabric 1.21.x)

This mod automatically releases golden apples at the perfect tick to guarantee early consumption timing on Minecraft 1.21+.

## Requirements

- **Minecraft**: `1.21` / `1.21.1`
- **Fabric Loader**: `>=0.16.0`
- **Fabric API**: Required
- **Java**: JDK 21+

## Features

- **Optimal Gapple Consumption Timing**: Cancels key press automatically upon golden apple consumption tick.
- **On-Screen Confirmation**: Displays an actionbar notification (`Gap Finished Early`) when active.

## Building from Source

To build the mod `.jar` file:

```bash
./gradlew build
```

The compiled mod JAR file will be located in `build/libs/`.
